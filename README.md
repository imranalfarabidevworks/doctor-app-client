# 🏥 DocAppoint - Your Digital Health Companion

**DocAppoint** is a streamlined healthcare platform designed to make medical appointments effortless. Patients can easily search for specialists, manage bookings, and maintain their health journey through a user-friendly interface.

## 🔗 Live Site Link
https://doctor-app-client-opal.vercel.app/

---

## 🚀 Key Features
* **Seamless Doctor Discovery:** An intuitive search system to find specialized doctors based on your needs.
* **Smart Booking System:** A dynamic, user-friendly appointment booking modal that ensures a smooth scheduling experience.
* **Personalized Patient Dashboard:** A dedicated dashboard for every user to view, edit, or manage their upcoming appointments.
* **Secure Authentication:** Built with **Better-Auth** for robust and secure user login and profile management.
* **Real-time Management:** Instant booking confirmations and the ability to delete or update appointments directly from the dashboard.

---

## 🛠 Tech Stack
This project is powered by modern web technologies:
* **Frontend:** Next.js, React, Tailwind CSS, HeroUI
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Authentication:** Better-Auth
